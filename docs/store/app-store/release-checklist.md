# App Store Release Checklist: Pocket Ahead

Before submitting Pocket Ahead to the iOS App Store, review the checklist to ensure alignment with Apple Review Guidelines. The current 1.0.0 release configuration targets Android and web only; this file is retained for a future iOS release.

---

## 1. Guideline Compliance
* [ ] **Guideline 5.1.1(v) - Deletion**: In-app account deletion is functional (`Profile > Privacy Centre > Delete My Account`).
* [ ] **Privacy Link**: Privacy Policy URL is active and matches the in-app document (`profile/legal/privacy`).
* [ ] **Support Link**: Working contact and FAQ portal (`profile/help`).
* [ ] **Publisher Review**: Confirm the publisher identity, monitored support contact, and applicable legal terms.
* [ ] **Safe Areas**: Verify bottom tab bar does not overlay the home indicator on iPhone devices.

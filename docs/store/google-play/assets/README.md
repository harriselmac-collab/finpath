# Google Play Preview Assets

These files are ready to upload to the English (United States) Play Store listing.

## Upload files

- `app-icon-512.png` - 512 x 512, 32-bit PNG with alpha, 14 KB.
- `feature-graphic-1024x500.png` - 1024 x 500, 24-bit PNG without alpha, 38 KB.
- `screenshots/en-US/01-dashboard.png` - 1080 x 1920, 24-bit PNG without alpha.
- `screenshots/en-US/02-plan.png` - 1080 x 1920, 24-bit PNG without alpha.
- `screenshots/en-US/03-transactions.png` - 1080 x 1920, 24-bit PNG without alpha.
- `screenshots/en-US/04-languages.png` - 1080 x 1920, 24-bit PNG without alpha.

The icon uses the supplied Pocket Ahead artwork from `assets/branding/app-icon-source.png`. The feature graphic uses the existing Pocket Ahead wordmark and exact brand palette; it does not add claims or third-party artwork. The screenshots are captures of the Android app UI, not promotional mockups. Concept mockups are intentionally excluded because they do not match the shipping interface.

## Suggested alt text

- Feature graphic: Pocket Ahead wordmark beside a simplified dashboard showing a covered plan, progress chart and spending bars.
- Dashboard: Pocket Ahead dashboard showing safe-to-spend total, daily allowance, next income date and remaining commitments.
- Plan: Financial life map showing a 12-month plan estimate, monthly obligations and a planning insight.
- Transactions: Transaction history with categorized grocery and coffee expenses, filters, search and quick add.
- Languages: Language selector showing English, French, Arabic, Spanish, German, Portuguese and Italian with country flags.

## Validation

The four phone screenshots use the recommended 9:16 portrait ratio and are at least 1080 pixels on the short side. Dimensions, color modes and alpha requirements were checked locally on 2026-08-11 against Google Play's preview-asset requirements.
